# KafkaEx Instructions

## Overview
These instructions apply only to source files in the KafkaEx project, excluding all test files.

## Scope
- **Applies to:** `producer1.py`, `consumer1.py`, `test.py`
- **Excludes:** `test_*.py`, `*_test.py`

## Code Style Guidelines

### Python Standards
- Use descriptive variable and function names
- Add docstrings to all functions
- Follow PEP 8 naming conventions
- Add type hints where applicable

### Kafka Integration
- Always include error handling (try/except blocks)
- Use connection timeouts to prevent hanging
- Close connections in finally blocks
- Log messages and errors clearly

### Documentation
- Document input parameters and return values
- Explain Kafka topic purposes and message formats
- Include comments for complex logic

## Restrictions
These instructions do **NOT** apply to:
- Test files (`test_*.py`, `*_test.py`)
- Pytest configurations
- CI/CD pipelines
